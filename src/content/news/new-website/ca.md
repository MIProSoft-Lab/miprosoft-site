---
title: El nostre nou web
summary: El grup ja té un web que reuneix les persones, les publicacions i les notícies, actualitzat a partir d'ORCID.
---

Hem estrenat un nou web per al grup. Hi trobareu:

- **Persones**: un perfil per a cada membre, amb les seves publicacions, formació i altres activitats.
- **Publicacions**: tots els articles del grup, un sol cop cadascun, amb un filtre per autor, dades de citacions i enllaços d'accés obert.
- **Notícies i blog**: anuncis i entrades sobre la nostra feina, com aquesta.

Les publicacions s'actualitzen automàticament a partir d'[ORCID](https://orcid.org), de manera que el web es manté al dia sense edició manual.
