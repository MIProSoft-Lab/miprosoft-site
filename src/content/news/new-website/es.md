---
title: Nuestra nueva web
summary: El grupo ya tiene una web que reúne a las personas, las publicaciones y las noticias, actualizada a partir de ORCID.
---

Hemos estrenado una nueva web para el grupo. En ella encontraréis:

- **Personas**: un perfil para cada miembro, con sus publicaciones, formación y otras actividades.
- **Publicaciones**: todos los artículos del grupo, una sola vez cada uno, con un filtro por autor, datos de citas y enlaces de acceso abierto.
- **Noticias y blog**: anuncios y entradas sobre nuestro trabajo, como esta.

Las publicaciones se actualizan automáticamente a partir de [ORCID](https://orcid.org), de modo que la web se mantiene al día sin edición manual.
